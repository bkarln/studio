# **App Name**: TaskFlow

## Core Features:

- User Authentication: Secure user registration and login via email and phone number with email confirmation for account activation and single active device limitation.
- Organization Management: Allow users to create, manage, and configure organizations. Organization creators can manage groups, add/remove members, invite users, and approve organization entry requests.
- Group Management: Enable organization admins to create and manage user groups within their organizations, facilitating task assignment to multiple recipients.
- Task Management: Create, assign tasks with descriptions, deadlines, attachments (images, audio, documents), and track task status (new, on time, delayed, completed).
- Task Extension Request: Implement a process for requesting task deadline extensions, including description, new proposed deadline, and approval workflow. Approval updates the task deadline.
- Task Progress Tracking: Log task progress with date/time, description, and attachments (images, audio, documents) to maintain a history of task activities.
- Automated Notifications: Schedule daily email/WhatsApp notifications with pending tasks and extension requests per organization. Send completion notifications to the task assigner.

## Style Guidelines:

- Primary color: Deep blue (#00008B) to convey professionalism and reliability.
- Secondary color: Red (#FF0000) for alerts and important actions.
- Background color: Light gray (#F0F0F0) for a clean and modern interface.
- Accent color: Light blue (#ADD8E6) for highlighting secondary actions and notifications.
- Body and headline font: 'Inter' for a modern and readable experience.
- Use a set of clear and consistent icons from a library like Material Design Icons to represent different task statuses, attachments, and actions.
- Employ a card-based layout for tasks to maximize scannability on mobile devices.
- Subtle animations for task status updates and transitions to provide feedback and enhance user experience.
